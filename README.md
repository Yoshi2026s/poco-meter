- [引継ぎ資料](docs/HANDOVER.md)
- [開発指示](AGENTS.md)

## 現在の状態

2026/11/06に旧オフライン配布版の案内から、ポコメーター番長専用の開発資料へ変更しました。
このリポジトリには、アプリ本体・依存設定・ビルド／テスト環境はまだありません。
Sitesの編集元ソースの移管と、現行公開版との照合が必要です。現行アプリの完全な複製として扱わないでください。

リポジトリは公開されています。秘密情報、認証トークン、利用者データ、アクセスログはコミットしないでください。
GitHub Pagesは今回の確認時点で未設定です。資料更新によるSitesの自動更新はありません。

## Claude Codeで開始する

```bash
git clone https://github.com/Yoshi2026s/-.git poco-meter
cd poco-meter
claude
```

Claude Codeへの最初の指示：

> CLAUDE.md、AGENTS.md、docs/HANDOVER.mdを読んで、現行Sitesの編集元ソースを確認してください。ソースが未取得なら不足するものを報告してください。取得後は公開版との差分と既存データを保全し、締め時間を変えても目標値が同じになるという過去報告を再現・調査してください。
