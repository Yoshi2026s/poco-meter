# 初期画面はシンプルモードのみ

初回・再読込時のシンプルメニューをON、独立アイテム目安をOFFに固定。以前の開閉設定では起動状態を復元しない。補助sectionは従来どおり全閉、detailsも全閉で初期化。詳細メーター・入力部分を閉じたdetailsにまとめ、必要時に開けるよう維持。起動時のURLフラグメントによる自動展開を停止し、画面での明示ナビゲーションは維持する。

検証中、最新ソース51e982fで入力メッセージやデフォルト設定の表示先要素が欠け、初期化時にnullへのアクセスで停止することを検出。以前の表示先の空要素と属性を必要な場所へ戻し、動的メッセージの表示と処理継続を修復。削除済みの説明文・名前ロゴは戻さない。時計の削除済み表示先は非表示のまま内部参照互換性を保持。

既存メニュー7件・E目標反映15件の計22テスト合格。追加の初期化確認では、保存HUD off/items onでもシンプルON・アイテム目安OFF、全details/section閉、明示開放、現在値保持を確認。DOM・ストレージ代替実装での確認。ブラウザ自動操作・実機検証なし。
