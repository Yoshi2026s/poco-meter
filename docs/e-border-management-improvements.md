# E帯の保存・管理改善 v2026.10.18.4

|対象|変更前|変更後|
|---|---|---|
|通常の相違置換|古い値は保存前コピーだけで次回保存で更新される|手入力・CSV・JSON結合の置換前の値を、ごみ箱にも保持|
|ごみ箱から値を置換して復元|現在の別の値はごみ箱に残らない|現在の値を入れ替えてごみ箱に残し、逆方向の復元も可能|
|ごみ箱の整合性|外部JSONの重複キーが曖昧|重複キーを拒否し、既存順序と最大100件を保持|
|検索条件|開き直すたびに設定し直す|ランク・締め・月・開始日・終了日・順序・概数条件を端末に保持|
|検索条件の異常|保存機能なし|形式検証、無効時の全件表示、解除状態の保存。記録本体は変更しない|
|読めなかった下書き|別キーに保管するが書出し入口なし|復旧欄から別保管の原文を書出し可能|

ごみ箱は同じ日・ランク・締めごとに1件、最大100件。全世代履歴ではない。現在値とごみ箱値が一致する復元はごみ箱項目を取り除く。明示確認がない相違置換は引き続き拒否する。

100ラウンドの自動レビュー・デバッグで各条件・実チェック数・レビュー対象を記録する。100個の独立した改修や、人間100人の審査とは数えない。ブラウザ自動デバッグと実機検証は未実施。

## 実際に変更した内容

- E1フィルタの不正なoption要素を修正し、E1/E2/E3を選択可能にした。
- 管理対象のランク・締め時間を保存し、昨日までの7日間の記録数、最新記録日、未記録日を表示。未記録日から直接入力できる。
- 手入力の対象日を昨日に設定し、同じ日の入力候補を重複させず再表示する。
- 保存済み記録の編集・削除、初期記録を含む削除状態の保存、ごみ箱100件と復元を追加。
- 編集で日付・ランク・締めが変わる場合、元記録を削除し新しい条件へ移動。編集前の値を確認してから保存する。
- 確認済みの候補だけを保存し、未確認の候補は残す。入力変更で確認チェックを解除する。
- 日付・ランク・締め・数値の下書きを自動保存し、再起動時に復元。編集元の情報も保持する。確認チェックは復元しない。
- 壊れた下書きを自動消去せず、新しい下書きで置き換えるときは元データを別キーに保管。元データの書出しも追加。
- 保存前の復元用コピー、保存後の読戻し、容量不足の検知、別タブの変更検知、Web Locks対応環境での排他保存を追加・強化。
- 別タブで変更されたら最新内容を再読込できる。入力候補は残して再確認を求める。
- JSONの結合取込に加え、明示確認付きの全状態復元に対応。初期記録の削除情報とごみ箱もバックアップする。
- CSVの入出力、UTF-8 BOM、CRLF、取込検証と不正な行の全体拒否を追加。
- 日付範囲・新旧順・K/Mの有無による検索、直近7日/30日、条件解除、0件時の案内を追加。
- カード単位のコピペ、絞り込みに合う全件のコピペ・CSV、閉じられる手動コピペ欄を追加。
- 数値の単位換算を整数計算へ変更し、1.001K=1001の境界で誤った大小判定を防ぐ。
- OCRの日付は対象期間の終了日を使い、13/22時締めで片方の日付しか読めない場合や不整合な期間は自動確定しない。
- 画像の内容ハッシュで同一画像を省略。ファイル単体・合計容量・画素数の上限を設け、画像を遅延表示する。
- 読取工程にタイムアウトと中止処理を追加。準備中・処理中の中止、遅れて生成されたWorkerの終了、進捗とオフライン表示に対応。
- 読取途中・失敗時も確認用画像と読取済みの項目を候補として残し、手入力で続けられるようにした。
- 読取失敗・保存失敗・処理中の連続操作を区別し、入力エラーと保存状況をアクセシブルな表示で伝える。

## 保存・公開の制約

画像と個人の順位・ポイント・ダイヤ等は保存・送信しない。記録・下書き・復元用コピーは利用中のブラウザ内。ブラウザデータ消去や別端末への引継ぎには書き出したJSONが必要。画像選択と確認が必要な半自動方式で、Pocochaの画面の無人取得は行わない。

既存の保存キーと旧JSONを維持し、任意の追加フィールドでごみ箱等を保持する。メーター本体の入力・D1〜S6の自動収集・公開設定・他ツールは変更しない。GitHubは既存のSites案内と移行バックアップを維持し、入口の名称・版のみ合わせる。
