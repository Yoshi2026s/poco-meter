# 要望・仕様メモ

画面・計算・E帯・過去ボーダーを変えるときに参照する。旧 docs/HANDOVER.md から移した原文。

## 維持・照合する要望
以下は要望履歴。実装済みとは限らない。

### 画面
- 特別な指示がなければ全体レイアウト維持。
- 「常時表示」は「シンプルメニュー」へ統一。
- 初期表示はシンプルメニュー、その他のメニューは閉じる。
- シンプルメニュー内の閉じるボタンは不要。
- 現在のコア数は初期値0、締め時間の下。
- 締めまでの残り時間は秒以下までリアルタイム表示。
- Pocochaサーバー時刻利用の要望あり。正式な取得経路を確認し、端末時刻を公式時刻と表示しない。
- 表示設定の右側に全体再読込ボタン。更新時は最終更新バージョンを表示。
- 現在値・目標値の入力をコンパクトにし、「目標まであと○○K」を強調。右側にパーセントゲージ。
- 目標候補は集計期間・ランク・目標ボーダー選択欄より上。
- 残りアイテム目安はシンプルメニュー内4列。
- 説明文は「目標メーターまでの残りコイン・アイテム数」。

### 計算・過去ボーダー
- 算出方法の初期設定は上位25％。
- HAISHIN Lab参照の方針。取得元、利用条件、対象日・ランク・締め時間を確認。
- 計算式は現行実装を確認し、推測で作らない。
- 過去ボーダーは独立した領域でスマホから検索・閲覧しやすくする。
- カレンダー日付選択、ボーダーカードのコピー。
- 過去ボーダー表示は小数点第1位を四捨五入して整数表示。保存精度と計算精度は別に扱う。

### 画像取り込み・E帯
- 一度の取り込み上限は30枚。
- 画像から日時、締め時間、ランク帯を判別。
- 入力側の管理ランク・締め時間へ一律分類せず、読み取り結果で分類。
- 不明項目は推測で確定しない。
- E帯は締め時間別に保存・表示・集計。
- 重複、部分失敗、読み取り誤り、保存失敗を扱う。
- 取り込み→保存→再読込→復元→計算反映まで確認。

### 管理・共通表示
- このツール専用の管理ページと、ツール別アクセス統計。
- 利用者向けの「お問い合わせ」「過去統計」リンク削除要望あり。過去ボーダー機能と混同しない。
- 自作ツール一覧・公式Instagramリンクは削除要望あり。免責事項は簡潔に。
- Yoshi1012ロゴは最下段左寄せ、ブルー×ブラック系。
- IP関連は現行収集項目、送信先、認証、公開範囲を確認。ログをリポジトリへ入れない。

## 検証の要点
- 締め時間ごとに異なる既知データ、同値が正当なケース、データなし、日付境界、0時跨ぎ。
- E帯の画像取り込みから再読込後の計算反映。
- 表示切替と設定の保存・復元。
- スマホ縦持ち・小画面・横持ち・低い画面。主要操作は原則48×48 CSS px以上。
- 物理端末とエミュレーションを区別。回数や成功を捏造しない。
- 保存失敗を成功表示しない。本番データを変更する検証は復元手段を先に確保。
