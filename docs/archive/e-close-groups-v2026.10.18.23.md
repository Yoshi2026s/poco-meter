# E帯の〆時間別表示

E帯保存画面の記録一覧を13・22・24時〆の3グループに分割。各グループの条件一致件数、全保存件数、最新保存日を表示。記録がない場合は「データ無し」、保存済みだが日付等のフィルタに合わない場合は「この表示条件ではデータ無し」と区別する。上部の保存状況にも全締めの保存件数を表示。

締めを指定した検索では対象グループのみ表示。各締め30件ずつを初回表示し、追加表示で各締めを30件ずつ増やす。一部の締めの大量記録で別の締めが初回一覧から隠れることを防止。CSV・コピペは従来どおり表示条件に合う全件。保存キー・レコード値・締め分類は変更しない。

関連10テスト合格：グループ、空欄、絞り込みによる非表示、各締めの段階表示、既存の1件保存・復旧・Eのみ削除。DOM/ストレージ代替実装で実施。ブラウザ自動操作・実機確認なし。
