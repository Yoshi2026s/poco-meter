以下は要望履歴。実装済みとは限らない。

### 画面
- 特別な指示がなければ全体レイアウト維持。
- 「常時表示」は「シンプルメニュー」へ統一。
- 初期表示はシンプルメニュー、その他のメニューは閉じる。
- シンプルメニュー内の閉じるボタンは不要。
- 現在のコア数は初期値0、締め時間の下。
- 締めまでの残り時間は秒以下までリアルタイム表示。
- Pocochaサーバー時刻利用の要望あり。正式な取得経路を確認し、端末時刻を公式時刻と表示しない。
- 表示設定の右側に全体再読込ボタン。更新時は最終更新バージョンを表示。
- 現在値・目標値の入力をコンパクトにし、「目標まであと○○K」を強調。右側にパーセントゲージ。
- 目標候補は集計期間・ランク・目標ボーダー選択欄より上。
- 残りアイテム目安はシンプルメニュー内4列。
- 説明文は「目標メーターまでの残りコイン・アイテム数」。

### 計算・過去ボーダー
- 算出方法の初期設定は上位25％。
- HAISHIN Lab参照の方針。取得元、利用条件、対象日・ランク・締め時間を確認。
- 計算式は現行実装を確認し、推測で作らない。
- 過去ボーダーは独立した領域でスマホから検索・閲覧しやすくする。
- カレンダー日付選択、ボーダーカードのコピー。
- 過去ボーダー表示は小数点第1位を四捨五入して整数表示。保存精度と計算精度は別に扱う。

### 画像取り込み・E帯
- 一度の取り込み上限は30枚。
- 画像から日時、締め時間、ランク帯を判別。
- 入力側の管理ランク・締め時間へ一律分類せず、読み取り結果で分類。
- 不明項目は推測で確定しない。
- E帯は締め時間別に保存・表示・集計。
- 重複、部分失敗、読み取り誤り、保存失敗を扱う。
- 取り込み→保存→再読込→復元→計算反映まで確認。
